# DshTray 

我不喜欢 `dsh web`运行时总挂着控制台窗口，稍不留神就容易误关掉。

试过用 `winsw` 把它封装成系统后台服务，能跑但 `dsh web` 本质是个用户态进程，硬做成服务会带来一堆交互问题，严重影响使用体验。

后来干脆用 WinForms 写了这个简单的小工具，用来在后台启动 `dsh web`。功能上支持系统托盘图标操作，并可以通过 `Edge` 浏览器的 PWA 模式打开 Web UI；如果没装 `Edge`，会自动降级到默认浏览器。服务端口默认 53080，可以在 config 文件中自行修改。

为减小分发文件体积，建议使用 `.NET Framework 4.6.2` 编译的版本。

注：**dsh** 需自行安装。
